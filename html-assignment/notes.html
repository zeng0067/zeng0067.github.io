My Notes

Here are some notes I have taken during my studies in the Interactive Media Design program at Algonquin College.


img
The <img> tag is used to embed images in an HTML document. It requires the src attribute to specify the path to the image file and the alt attribute to provide alternative text for accessibility.
ul
The <ul> tag is used to create an unordered list. It contains <li> elements that represent individual list items. Unordered lists are typically displayed with bullet points.
blockquote
The <blockquote> tag is used to indicate that the enclosed text is an extended quotation. It is usually displayed as an indented block of text. The <cite> tag can be used within a <blockquote> to reference the source of the quotation.
dl
The <dl> tag is used to create a description list. It contains <dt> elements that represent terms and <dd> elements that represent descriptions.
abbr
The <abbr> tag is used to represent an abbreviation or acronym. It can include a title attribute that provides the full expansion of the abbreviation when hovered over.
